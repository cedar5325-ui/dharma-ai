# 다르마(DHARMA) AI 홈페이지

## 구성
1. 만화 캐릭터 홈페이지 메인화면
2. 스크롤 아래 차별화된 서비스
3. 결제 가능한 영역
4. 시스템 설명
5. 로그인 / 회원가입 / 마이페이지 데모
6. Google Drive 연동 준비 화면

## 실행
```bash
npm.cmd install
npm.cmd run dev
```

## 확인 주소

http://localhost:3000
http://localhost:3000/login
